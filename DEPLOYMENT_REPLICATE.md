# Replicate Deployment, Setup, Data & Experiments

Notes for running **selective face anonymization for lecture videos** on Replicate, plus how the
data/experiments are stored. Authored 2026-06-21.

## Live model
- **https://replicate.com/divide-by-0/deface-selective** (private, hardware `gpu-t4`)
- Cog source: [`replicate/cog.yaml`](replicate/cog.yaml) + [`replicate/predict.py`](replicate/predict.py)
- **Interface:** `video` (URL or file) + `keep_person_images` (1+ reference images of the person to **keep unblurred**) + `replacewith` / `thresh` / `reid_threshold` / `keep_audio` → anonymized video.
- Verified end-to-end with a real prediction (succeeded; ~14 min/clip on T4 — bump to `gpu-l40s`/`gpu-a100-large` for speed).

## Pipeline (what actually runs)
CenterFace (face detect + blur, ONNX) → YOLO11x (person detect) → TorchReID osnet (re-identify the lecturer)
→ OpenCV CSRT tracking → selective blur (everyone **except** the matched target person).

### Real runtime dependencies
`requirements.txt` overstates this — TensorFlow / TensorRT / DeepFace are listed but **not used at runtime**
(only in unused export tooling). The actual deps:

- `torch==2.0.1`, `torchvision==0.15.2` (CUDA 11.8)
- `ultralytics==8.3.0` (YOLO11)
- `torchreid` + `tensorboard` (re-id; see gotcha below)
- `onnxruntime-gpu==1.16.3` (CenterFace)
- `opencv-contrib-python==4.10.0.84` (the CSRT tracker lives in `contrib`)
- `imageio`, `imageio-ffmpeg`, `scikit-image`, `shapely`, `scipy`, `tqdm`, `Pillow`, `numpy`, `gdown`
- system: `ffmpeg`, `libgl1-mesa-glx`, `libglib2.0-0`

### Import gotchas (already handled in the Cog build; apply these if running the repo directly)
1. `deface/main.py` imports `fastreid` (top of file) but **never uses it** → comment those lines out
   (avoids `ModuleNotFoundError`; fastreid/detectron2 are not needed).
2. The **vendored** `reid/torchreid` is incomplete (missing `data/datasets`). Use the **pip** package instead:
   change `from reid.torchreid.utils import FeatureExtractor` → `from torchreid.reid.utils import FeatureExtractor`
   and `pip install torchreid tensorboard`.
3. `main.py` mixes `from deface.centerface ...` with bare `from recognition ...` / `from tracking ...`, so run with
   **cwd = repo root** and `PYTHONPATH=<repo>:<repo>/deface`.
4. `deface/_version.py` is generated by setuptools_scm from git tags — create it manually (`__version__ = "1.0.0"`)
   if building from a context without `.git`.

Gitignored (`*.pt`), kept at repo root / `models/`:

| `yolo11x.pt` | 109 MB | Ultralytics (auto-downloads) — YOLO11x person detector |

All three *used* weights are baked into the Replicate image.

## Data layout & how to get it
**Input layout** (per the README): an input directory with one folder per video; each folder contains
`video.mp4` + a `target_person/` folder with 1+ reference images (full-body, multiple angles) of the lecturer
to keep unblurred. Output `anonymized_video.mp4` is written into each folder.

Lecture videos + target images are **user-supplied**. The experiment data (below) is preserved in **GCP snapshots**
(project `coursetexts`):
- `deface1-backup-20260621` (93 GiB) and `deface2-backup-20260621` (39 GiB)
- Retrieve: `gcloud compute disks create restore-deface --source-snapshot=deface1-backup-20260621 --zone=us-central1-a`,
  attach to a VM, mount. Repo + data at `/home/manavgoyalid2/deface-with-selective-face-blurring/`.

The original `deface1`/`deface2` GCE disks were deleted after the Replicate model was verified (these snapshots are the backup).

## Replicate config — what's there and what's NOT
**In the image:** the `deface/` code, `predict.py` wrapper, and the 3 used weights (yolo11x, osnet, centerface).
**Not in the image:** the experiment datasets (`dataset1-3`, `test*`), `face_yolov9c.pt` (unused), and the unused
heavy deps (TF/TensorRT/DeepFace). Hardware `gpu-t4`; visibility `private`.

`predict.py` accepts `video` + a list of `keep_person_images`, reconstructs the expected input-dir structure
(`job/video.mp4` + `job/target_person/*.jpg`), runs `deface/main.py` via subprocess, and returns the anonymized video.

## Experiments run (preserved in the snapshots)
- **`dataset1`, `dataset2`, `dataset3`** (~3.5 GB each): full lecture videos (~1.2 GB `video.mp4` + 6 target reference
  images `a1..a6.jpg`) → `anonymized_video.mp4` (~710 MB) produced. The main selective-anonymization runs on real footage.
- **`test`, `test1`, `test3`, `test4`, `test5`** (8–54 MB): short clips used to tune parameters and validate the
  partial-segment workflow.
- Tuning knobs exercised: `--thresh` (face detection), `--reid-threshold` (lecturer-match strictness),
  `--max-frames-without-faces` (tracking persistence through occlusion), and `--debug-start`/`--debug-duration`
  partial-segment reprocessing (combined with [mitsoul/multi-cam_video_editor](https://github.com/mitsoul/multi-cam_video_editor)).
